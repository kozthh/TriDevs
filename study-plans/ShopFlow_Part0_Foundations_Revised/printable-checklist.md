# ShopFlow Part 0 - Foundations: Printable Checklist

## Daily Rules
- [ ] Study for 2 to 3 hours.
- [ ] Work 6 days.
- [ ] Use day 7 for retrospective.
- [ ] Write one short summary.
- [ ] Write one open question.

## Week 1: Document map and first pass

### Day 1
- [ ] Read the title and headings.
- [ ] Write the document outline.
- [ ] List 10 unfamiliar terms.

### Day 2
- [ ] Read the opening section.
- [ ] Write the PDF purpose in one paragraph.
- [ ] Record the main problem it solves.

### Day 3
- [ ] Read the next section.
- [ ] Define repeated ideas in one sentence each.
- [ ] Add one example per idea.

### Day 4
- [ ] Re-read the first major concept section.
- [ ] Convert prose into bullets.
- [ ] Note assumptions.

### Day 5
- [ ] Review the first four days of notes.
- [ ] Build a glossary.
- [ ] Mark vague concepts.

### Day 6
- [ ] Rebuild the outline from memory.
- [ ] Explain the document in your own words.
- [ ] Mark sections for a second pass.

### Day 7
- [ ] Review the week.
- [ ] Note clear points and weak points.
- [ ] Choose the first reread for week 2.

## Week 2: Core concepts and vocabulary

### Day 8
- [ ] Re-open the outline and glossary.
- [ ] Read the next major section.
- [ ] Write the section goal.

### Day 9
- [ ] Break the section into smaller ideas.
- [ ] Write one sentence per idea.
- [ ] Add questions beside unclear ideas.

### Day 10
- [ ] Focus on examples and diagrams.
- [ ] Reconstruct each example from memory.
- [ ] Compare your version to the PDF.

### Day 11
- [ ] Re-read the section for precision.
- [ ] Replace vague wording.
- [ ] Add missing definitions.

### Day 12
- [ ] Create a one-page summary sheet.
- [ ] Include definitions and relationships.
- [ ] Keep it short.

### Day 13
- [ ] Test recall without the PDF.
- [ ] Write or say the main ideas.
- [ ] Mark weak points.

### Day 14
- [ ] Review the week.
- [ ] Clean up notes.
- [ ] Decide what to repeat later.

## Week 3: Application and mental models

### Day 15
- [ ] Review summary sheets.
- [ ] Identify the strongest mental model.
- [ ] Write it as a flow.

### Day 16
- [ ] Read the next section for cause and effect.
- [ ] Note what depends on what.
- [ ] Add arrows or numbered steps.

### Day 17
- [ ] Focus on constraints and tradeoffs.
- [ ] Write pros and cons.
- [ ] Capture warnings.

### Day 18
- [ ] Revisit the examples.
- [ ] Reproduce the logic without looking.
- [ ] Compare and correct.

### Day 19
- [ ] Build a one-page review note.
- [ ] Separate core ideas from details.
- [ ] Put reusable ideas at the top.

### Day 20
- [ ] Do a closed-book recap.
- [ ] Teach the PDF to yourself.
- [ ] List concepts that still need work.

### Day 21
- [ ] Retrospective day.
- [ ] Review the week.
- [ ] Pick the top 3 topics to revisit.

## Week 4: Consolidation and final recall

### Day 22
- [ ] Read only your summaries.
- [ ] Spot missing gaps.
- [ ] Add short corrections.

### Day 23
- [ ] Create a final glossary.
- [ ] Keep definitions short and exact.
- [ ] Remove duplicates.

### Day 24
- [ ] Write a final one-page summary.
- [ ] Include purpose, structure, and lessons.
- [ ] Keep it easy to scan.

### Day 25
- [ ] Rebuild the outline from memory.
- [ ] Compare it to the PDF structure.
- [ ] Fix missing sections.

### Day 26
- [ ] Re-read the weakest pages.
- [ ] Rewrite those notes more clearly.
- [ ] Make them easier to revisit.

### Day 27
- [ ] Create a final revision sheet.
- [ ] Put the most important ideas on one page.
- [ ] Add one future practice item.

### Day 28
- [ ] Do a final closed-book self-test.
- [ ] Explain the PDF from memory.
- [ ] Check whether it is clean and complete.

### Day 29
- [ ] Review the self-test results.
- [ ] Correct the mistakes.
- [ ] Write the last unclear topic.

### Day 30
- [ ] Final retrospective.
- [ ] Write the overall lesson.
- [ ] Decide how to review this later.
