# TriDevs - Daily Development Tasks & Curriculum Tracker

## 📋 Team Structure
- **Team Size**: 3 Developers
- **Project**: ShopFlow E-Commerce Platform
- **Curriculum Duration**: 30+ days per module
- **Study Materials**: 6 comprehensive modules

---

## 📚 Curriculum Overview

### Module Structure
1. **Part 0: Foundations** - Core concepts (Days 1-30)
2. **Part A: Backend Engineering** - Server-side architecture (Days 31-60)
   - Java Track (Developer 1)
   - C++ Track (Developers 2 & 3)
3. **Part B: Frontend Engineering** - Client-side development (Days 61-90)
4. **Part C: Deployment & Cloud** - DevOps & infrastructure (Days 91-120)
5. **Part D: DSA Curriculum** - Data structures & algorithms (Days 121-150)
6. **Part E: Career Readiness** - Interview prep & soft skills (Days 151-180)

---

## 🎯 Daily Task Format

Each day consists of:
- **Study Material**: Reading/learning from PDF
- **Code Exercises**: Practical implementation
- **Code Review**: Peer feedback
- **Reflection**: Daily summary & learnings
- **Submission**: Push to work submission folder

### Time Allocation (Daily)
- Morning (2 hours): Study & Learning
- Mid-morning (1.5 hours): Coding exercises
- Lunch Break
- Afternoon (2 hours): Implementation project
- Late Afternoon (1 hour): Code review & documentation
- **Total Daily Commitment**: ~6.5 hours coding + study

## 📅 Daily Task Submission Process

### Step 1: Create Daily Folder
```
Date: YYYY-MM-DD
Location: Daily_Work/[Module]/[Developer_Name]/[YYYY-MM-DD]/
```

### Step 2: Daily Deliverables
- `study_notes.md` - Key takeaways from study material
- `code_exercise.java` or `code_exercise.cpp` - Exercise implementation
- `reflection.md` - Lessons learned & challenges
- `code_review_checklist.md` - Code review self-assessment

### Step 3: Daily Submission Checklist
- ✅ Study material reviewed
- ✅ Code exercises completed
- ✅ All code properly commented
- ✅ Self-review done
- ✅ Daily reflection written
- ✅ Pushed to Git

## 📞 Support & Escalation

### Blockers Resolution Process
1. **Level 1**: Team peer help (same track)
2. **Level 2**: Cross-track mentor (different language)
3. **Level 3**: Architecture review (design issues)
4. **Level 4**: Instructor consultation (concept gaps)

### Escalation Timeline
- Blocker reported immediately in standup
- Level 1 resolution within 2 hours
- Level 2 resolution within 4 hours
- Level 3 resolution within 1 day
- Level 4 resolution within 2 days
